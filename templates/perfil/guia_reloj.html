    Conectar el Apple Watch

    Vamos a hacer que el iPhone envíe tus pasos a Niebla Mental cada noche, solo. Se hace una vez y tarda unos 15 minutos. Son dos partes: primero un atajo (lo que hay que hacer) y después una automatización (cuándo hacerlo).

    📋 Antes de nada, ten a mano dos cosas:

    1. La dirección de la app: {{ url_api }}
    2. Tu clave personal (empieza por nm_). Créala en Salud → ⌚ Conectar → «🔑 Crear mi clave» y pégala en una nota del iPhone: solo se muestra una vez.

    Esta guía es para la versión actual de iOS (Atajos con el botón ＋ redondo abajo). Si algo no te sale igual, haz una captura y pide ayuda.

    {# ───────────── PARTE 1: EL ATAJO ───────────── #}
    Parte 1 · Crear el atajo «Pasos Niebla Mental»
      {% call paso(1, "Abre la app «Atajos»") %}

      Viene con el iPhone. Su icono son dos cuadrados de colores superpuestos. Si no la ves: desliza hacia abajo en la pantalla de inicio y escribe Atajos.

      {% endcall %} {% call paso(2, "Toca el ＋ redondo de abajo") %}

      Se abre un atajo nuevo con un cuadro «¿Qué quieres que haga el atajo?». No escribas nada ahí.

      {% endcall %} {% call paso(3, "Toca «Editar», arriba a la derecha") %}

      Se abre el editor, con un buscador abajo.

      {% endcall %} {% call paso(4, "Ponle nombre") %}

      Toca el nombre de arriba («Nuevo atajo ⌄») → Cambiar nombre → escribe Pasos Niebla Mental.

      {% endcall %} {% call paso(5, "En el buscador escribe «muestras» y toca «Buscar muestras médicas»") %}

      La del corazón rojo. Si el iPhone pide permiso para acceder a Salud, acéptalo.

      {% endcall %} {% call paso(6, "En «Tipo» elige «Pasos»") %}

      Puede aparecer en inglés: Steps. Es lo mismo.

      {% endcall %} {% call paso(7, "En «Fecha de inicio», cambia «está entre los últimos 7 días» por «es hoy»") %}{% endcall %} {% call paso(8, "En «Agrupar por», elige «Día»") %}

      Aparece un interruptor «Completar las que faltan»: desactívalo (gris).

      {% endcall %} {% call paso(9, "Busca «detalles» y toca «Obtener detalles de muestra médica»") %}

      En la palabra azul elige Valor. Queda: Obtener Valor de Muestras médicas.

      {% endcall %}
    Parte 2 · Enviar los pasos a Niebla Mental
      {% call paso(10, "Busca «URL» y toca «Obtener contenido de URL»") %}

      Tiene que quedar la última, debajo de «Obtener Valor». Si se coloca más arriba, mantenla pulsada y arrástrala abajo.

      {% endcall %} {% call paso(11, "Cambia lo azul que sale después de «Obtener contenido de» por la dirección") %}

      El iPhone suele poner «Valor» ahí: tócalo, bórralo y pega la dirección de arriba (https://…/api/salud).

      {% endcall %} {% call paso(12, "Toca el círculo azul con la flecha (⌄) para ver más opciones") %}{% endcall %} {% call paso(13, "En «Método», elige «POST»") %}{% endcall %} {% call paso(14, "Toca «Cabeceras» → «Añadir nueva cabecera»") %}

      Se crea una fila con dos huecos. Los dos van en la misma fila:

      • Hueco de la izquierda (pone «Clave»): Authorization
      • Hueco de la derecha (pone «Texto»): Bearer, un espacio y tu clave → Bearer nm_xxxx…

      ⚠️ No pulses «Añadir nueva cabecera» dos veces: tiene que quedar una sola fila.

      {% endcall %} {% call paso(15, "En «Cuerpo de la solicitud» deja «JSON» y toca «Añadir nuevo campo» → «Número»") %}
      • Izquierda: pasos
      • Derecha: toca el hueco y, en la barra de encima del teclado, elige la variable ❤️ Valor.
      {% endcall %} {% call paso(16, "Pruébalo con ▶ (abajo a la derecha)") %}

      Debajo tiene que salir: «Guardado en Niebla Mental: 494 pasos ✓». Si sale un error, revisa los pasos 10–15.

      {% endcall %} {% call paso(17, "Sal con la flecha ‹ de arriba a la izquierda") %}

      El atajo se guarda solo.

      {% endcall %}
    {# ───────────── PARTE 3: LA AUTOMATIZACIÓN ───────────── #}
    Parte 3 · Que lo haga solo cada noche
      {% call paso(18, "En la pantalla principal de Atajos, entra en «Automatización»") %}{% endcall %} {% call paso(19, "Toca el ＋ redondo de abajo → «Editar»") %}

      Se abre como si fuera un atajo nuevo. Es normal.

      {% endcall %} {% call paso(20, "En la lista de abajo, toca el botón azul «⏱ Automatización»") %}

      Aparecen opciones como Momento del día, Alarma, Sueño, Llegar…

      {% endcall %} {% call paso(21, "Toca «Momento del día»") %}
      • A la hora: 22:00 (o cuando sueles usar el móvil: bloqueado no deja leer Salud).
      • Repetir: Cada día.
      • Automatización: activada (verde). Así se ejecuta sola.
      • Notificaciones: como prefieras.
      {% endcall %} {% call paso(22, "Busca «ejecutar» y toca «Ejecutar atajo» → elige «Pasos Niebla Mental»") %}

      «Entrada» déjalo como está.

      {% endcall %} {% call paso(23, "Sal con la flecha ‹") %}

      ¡Listo! 🎉 Cada noche tus pasos aparecerán en Salud → Actividad con la etiqueta ⌚ del reloj.

      {% endcall %}
