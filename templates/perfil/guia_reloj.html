    Conectar el Apple Watch

    Vamos a hacer que el iPhone envíe tus pasos a Niebla Mental cada noche, solo. Se hace una vez y tarda unos 10 minutos. Ve paso a paso: una cosa en cada paso.

    📋 Antes de nada, necesitas dos cosas. Cópialas cuando la guía te lo pida:

    1. La dirección de la app: {{ url_api }}
    2. Tu clave personal (empieza por nm_). Se crea en Salud → ⌚ Conectar → «🔑 Crear mi clave». Si ya la creaste y no la guardaste, crea una nueva.
    {# ───────────── PARTE 1 ───────────── #}
    Parte 1 · Abrir Atajos y crear la automatización
      {% call paso(1, "Busca la app «Atajos» en tu iPhone") %}

      Es una app de Apple que ya viene instalada. Su icono son dos cuadrados de colores superpuestos (azul y rosa). Si no la encuentras: en la pantalla de inicio, desliza el dedo hacia abajo en el centro, escribe Atajos y tócala. Si no aparece, descárgala gratis en la App Store.

      {% endcall %} {% call paso(2, "Toca «Automatización», abajo") %}

      Abajo de la pantalla verás tres pestañas: Atajos · Automatización · Galería. Toca la del medio.

      {% endcall %} {% call paso(3, "Toca «Nueva automatización»") %}

      Es un botón grande en el centro. Si ya tienes alguna automatización, es el ＋ de arriba a la derecha.

      {% endcall %} {% call paso(4, "Toca «Hora del día»") %}

      Es la primera opción de la lista, con un reloj.

      {% endcall %} {% call paso(5, "Elige la hora: 22:00") %}

      Toca la hora que aparece y ponla a las 22:00 (o a la hora en que sueles mirar el móvil antes de dormir: con el móvil bloqueado, Apple no deja leer los datos de salud).

      {% endcall %} {% call paso(6, "Comprueba que pone «Diariamente»") %}

      Debajo de la hora tiene que estar marcado Diariamente.

      {% endcall %} {% call paso(7, "Marca «Ejecutar inmediatamente»") %}

      Más abajo hay dos opciones: Ejecutar tras confirmación y Ejecutar inmediatamente. Marca la segunda, así no te preguntará cada noche.

      {% endcall %} {% call paso(8, "Toca «Siguiente», arriba a la derecha") %}{% endcall %} {% call paso(9, "Toca «Nueva automatización en blanco»") %}

      Se abre una pantalla casi vacía con un botón Añadir acción. Aquí vamos a poner las piezas.

      {% endcall %}
    {# ───────────── PARTE 2 ───────────── #}
    Parte 2 · Leer tus pasos de hoy
      {% call paso(10, "Toca «Añadir acción»") %}

      Se abre un buscador abajo.

      {% endcall %} {% call paso(11, "Escribe «muestras» y toca «Buscar muestras de salud»") %}

      Tiene un corazón rojo. Aparece una caja que dice algo como «Buscar todas las muestras de salud de tipo Tipo».

      {% endcall %} {% call paso(12, "Toca la palabra azul «Tipo» y elige «Pasos»") %}

      Usa el buscador de arriba si no lo ves. La primera vez el iPhone te pedirá permiso para leer Salud: acéptalo.

      {% endcall %} {% call paso(13, "Toca «Añadir filtro» y deja «Fecha de inicio · es hoy»") %}

      Al añadir el filtro suele salir ya Fecha de inicio · está en los últimos 7 días: toca «está en los últimos» y cámbialo a es hoy.

      {% endcall %} {% call paso(14, "Toca «Agrupar por» y elige «Día»") %}

      Así suma todos tus pasos del día en un solo número.

      {% endcall %} {% call paso(15, "Toca «Añadir acción» de nuevo y busca «Obtener detalles de muestras de salud»") %}

      Aparece debajo de la anterior. En la palabra azul elige Valor. Ese número son tus pasos de hoy.

      {% endcall %}
    {# ───────────── PARTE 3 ───────────── #}
    Parte 3 · Enviarlos a Niebla Mental
      {% call paso(16, "Añadir acción → busca «Obtener contenido de URL»") %}

      Tiene un icono azul de flecha. Aparece una caja con la palabra URL.

      {% endcall %} {% call paso(17, "Toca «URL» y pega la dirección de la app") %}

      La que copiaste arriba (empieza por https:// y acaba en /api/salud).

      {% endcall %} {% call paso(18, "Toca la flechita «›» de la caja para ver más opciones") %}{% endcall %} {% call paso(19, "En «Método», elige «POST»") %}{% endcall %} {% call paso(20, "En «Encabezados», toca «Añadir nuevo encabezado»") %}

      Aparecen dos huecos: Clave y Texto.

      • En Clave escribe: Authorization
      • En Texto escribe Bearer, un espacio y pega tu clave. Queda así: Bearer nm_xxxxxxxx…
      {% endcall %} {% call paso(21, "En «Cuerpo de la solicitud», elige «JSON»") %}{% endcall %} {% call paso(22, "Toca «Añadir nuevo campo» → «Número»") %}
      • En Clave escribe: pasos
      • En Número, toca el hueco y, en la barra que aparece encima del teclado, elige Detalles de muestras de salud (la variable azul del paso 15).
      {% endcall %} {% call paso(23, "(Opcional) Añadir acción → «Mostrar notificación»") %}

      En el texto, elige la variable Contenido de la URL. Cada noche verás «Guardado: 8345 pasos ✓».

      {% endcall %} {% call paso(24, "Toca «OK» arriba a la derecha") %}

      ¡Ya está guardada! 🎉

      {% endcall %}
    {# ───────────── PARTE 4 ───────────── #}
    Parte 4 · Probarla ahora (sin esperar a las 22:00)
      {% call paso(25, "En «Automatización», toca la que acabas de crear") %}{% endcall %} {% call paso(26, "Toca el botón ▶ de abajo") %}

      Si sale la notificación «Guardado…», abre Niebla Mental → Salud → Actividad: ahí estarán tus pasos con la etiqueta ⌚ del reloj.

      {% endcall %}

    ¿Sale un error o algo no aparece igual? Haz una captura y mándamela: lo miramos juntas. Cuando esto funcione, añadimos el sueño (es parecido).
